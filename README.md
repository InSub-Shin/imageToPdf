# ImageToPDF

이미지 파일들을 PDF로 병합하는 Windows 데스크탑 애플리케이션 (단일 `.exe` 배포)

---

## 주요 기능

### 🖼 탭 1 — 드래그 & 드롭
| 기능 | 설명 |
|------|------|
| 드래그 & 드롭 | 드롭 영역에 이미지를 드래그하거나 **클릭**하면 파일 선택 창 오픈 |
| 파일 / 폴더 추가 | 개별 파일 추가 또는 폴더 일괄 추가 |
| 순서 조정 | ▲ ▼ 버튼으로 순서 변경 |
| 이미지 회전 | 선택 이미지를 **시계 / 반시계** 방향으로 90° 회전 (PDF에 반영) |
| 미리보기 패널 | 목록에서 행 선택 시 우측에 썸네일 즉시 표시 |
| 중복 파일명 처리 | 같은 이름의 PDF가 있으면 자동으로 `(1)`, `(2)` ... 넘버링 |

### ⚙ 탭 2 — 커스텀 파싱
| 기능 | 설명 |
|------|------|
| 파싱 설정 | 구분자 · 그룹 인덱스 · 상세 인덱스 · 정렬 인덱스 자유 설정 |
| 툴팁 | 각 설정 항목에 상세 설명 및 예시 툴팁 제공 |
| 실시간 미리보기 | 파일명 예시 입력 시 파싱 결과 실시간 표시 |
| 이미지 목록 | 파일 추가 / 폴더 열기 / ▲▼ 순서 조정 / 삭제 |
| 그룹 미리보기 | 버튼 클릭 시 그룹 키 · 파일 수 · 상세 목록 · 출력 PDF명 팝업 |
| 초기화 | 파싱 설정을 기본값으로 리셋 |

### 🏢 탭 3 — 장기계약팀 전용
| 기능 | 설명 |
|------|------|
| 파일명 규칙 | `약어_보관일자_서식코드_증권번호_서식코드_순번_IMG_이미지명_순번.TIF` |
| 자동 그룹핑 | 증권번호(index 3) 기준 자동 그룹핑 |
| 자동 정렬 | 서식코드 ASC → 순번 ASC |
| PDF 파일명 | 증권번호 또는 증권번호_서식코드목록 선택 |
| 초기화 | 폴더 경로 · 스캔 결과 · 미리보기 전체 초기화 |

### 공통
- **라이트 / 다크 모드** 전환 (우상단 버튼)
- 비동기 PDF 생성 (진행률 표시, UI 블로킹 없음)
- 단일 `.exe` 파일로 배포 — 별도 설치 불필요

## 설치 및 실행

### Python으로 직접 실행
```bash
pip install -r requirements.txt
python main.py
```

### EXE 빌드 (Windows)
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ImageToPDF main.py
# dist\ImageToPDF.exe 생성
```
